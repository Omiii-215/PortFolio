Project Overview

The goal was to port the powerful spectral-timing capabilities of the Python Stingray library to the Julia ecosystem. When dealing with millions of X-ray photons and computing averaged cross-spectra over thousands of segments, Julia's speed becomes a game-changer. Over three months, I built a complete high-performance spectral timing engine from scratch under the OpenAstronomy umbrella.

What Was Delivered

High-Level Spectral Types — Implemented Powerspectrum and Crossspectrum struct types from scratch with a clean, type-safe API.

Mission-Specific FITS Support — Added telescope-specific event file readers for NICER, NuSTAR, XMM-Newton, and RXTE.

Frequency Rebinning — Implemented both geometric (logarithmic) and linear frequency rebinning for broadband noise studies.

Robust Normalizations — Added Leahy, Fractional RMS, and Absolute RMS normalizations, tested against Poisson noise statistics.

Lomb-Scargle Periodograms — Ported the Lomb-Scargle algorithm to handle unevenly sampled astrophysical data.

Fourier Utilities & Testing — Ported shift_and_add for dynamic spectral analysis. Integrated Codecov for test coverage.
